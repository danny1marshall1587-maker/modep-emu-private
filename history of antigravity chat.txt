1. Root Cause of DAW Not Loading
The multi-track DAW application is openDAW Studio (a modern WebAssembly / AudioWorklet browser DAW). These applications strictly require crossOriginIsolated mode in the browser:

SharedArrayBuffer and Atomics for multi-threaded WebAssembly audio processing.
Browsers (Chrome/Safari/Firefox) refuse to enable SharedArrayBuffer unless the host provides Cross-Origin Isolation headers (Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp), or runs a service-worker polyfill (coi-serviceworker).
Since the Pi’s MODEP Tornado server serves plain HTTP over the local IP without TLS, modern browsers block cross-origin isolation unless intercepted by a client-side ServiceWorker.
